Task: Import Quizzes + Import Questions — Backup & Migration
Recommendation: Build Now — 2 màn hình riêng trên Import/Export.

1. Business Goal

Cho phép instructor import file nhiều quiz (kèm questions) vào course, và import questions rời vào quiz/content bank — giảm nhập tay, tăng tốc content migration.

2. Problem Statement

Chỉ import questions là chưa đủ: user cần 1 file chứa nhiều quiz + questions, chọn course đích, tạo cả quiz. Hai nhu cầu này phải tách 2 màn hình rõ ràng.

3. Target Users

  • Admin / lp_instructor
  • Agency setup course content hàng loạt

4. Functional Requirements

  • Tab Import Quizzes: chọn course (bắt buộc) + default section fallback; multi-quiz CSV/JSON có optional section_name.
  • Group theo section_name + quiz_title / quizzes[].section_name + title; tạo/find section, tạo quiz + questions; attach curriculum section.
  • Tab Import Questions: existing quiz hoặc content bank; insert position; override-by-title trong quiz.
  • CSV + JSON samples riêng cho multi-quiz và questions.
  • Validate + preview + text error log + batch progress.
  • Settings: max size/rows/answers/batch (admin).
  • Không entry Tools; caps edit course/quiz hiện có.

5. UI References

output/wireframes/index.html — Flow A (a01–a04), Flow B (b01–b04), S05/S06.

6. Technical Notes

  • LP_Quiz_CURD, LP_Question_CURD, LP_Section_CURD::add_items_section
  • AJAX: upload_validate_quizzes, process_quiz_batch (1 quiz/group per request)
  • MVP path: mvp/learnpress-import-export/

7. Acceptance Criteria

  • 2 tabs riêng Import Quizzes + Import Questions trên Import/Export.
  • Multi-quiz file tạo ≥2 quizzes trong các section khai báo trong file.
  • Same section_name + quiz_title → 1 quiz; questions attach đúng.
  • Questions-only: existing quiz + content bank hoạt động.
  • Không course / không quiz_title → error rõ.

8. Subtasks

  • Docs/wireframes đã align 2 flows (output/).
  • QA multi-quiz CSV + JSON + course attach.
  • QA questions-only + permissions instructor.
  • EN docs 2 pages trong add-on docs.

9. Release Notes

Backup & Migration: Import Quizzes (multi-quiz into a selected course, grouped by section_name + quiz_title) and Import Questions (into a quiz or content bank). CSV/JSON samples, validation, batched progress. Open LearnPress → Import/Export.
