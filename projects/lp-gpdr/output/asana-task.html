Asana Task Preview

[Feature] LearnPress Cookie Consent Native Core Integration

1. Business Goal

Tích hợp tính năng Cookie Consent native vào LearnPress Core nhằm đáp ứng tiêu chuẩn GDPR/ePrivacy cho 95% website đào tạo, san bằng khoảng trống tính năng với Tutor LMS, giảm 40% ticket hỗ trợ liên quan đến xung đột plugin cookie bên thứ 3 và nâng cao trải nghiệm người dùng.

2. Problem Statement

Các website LearnPress hiện phải cài thêm các plugin cookie bên thứ ba (như Complianz, Cookiebot) gây cồng kềnh, bất đồng bộ giao diện, phát sinh lỗi cache trang bài học và tốn thêm chi phí bảo trì.

3. Target Users

  • Administrator: Quản lý và cấu hình toàn bộ cài đặt Cookie Banner trong WP Admin.
  • Student & Guest: Tiếp nhận Banner, chọn đồng ý hoặc tùy chỉnh tùy chọn cookie.
  • Developer: Sử dụng JS API và PHP Hooks để đấu nối với Google Analytics, GTM, Meta Pixel.

4. Functional Requirements

  • Cấu hình Admin tại LearnPress → Settings → Privacy & Cookies với 6 Sub-tabs (General, Appearance, Content, Behavior, Developer, Compatibility).
  • Hỗ trợ 5 vị trí Banner: Bottom Bar (Default), Top Bar, Floating Left, Floating Right, Center Modal.
  • Hỗ trợ 2 chủ đề giao diện: Light Theme (Default) và Dark Theme.
  • Hỗ trợ 4 nhóm Cookie tiêu chuẩn: Essential (Bắt buộc ON), Analytics, Marketing, Preferences.
  • Cung cấp các thao tác: Accept All, Reject All, Customize, Save Preferences.
  • Popup tùy chọn Cookie Preferences với mô tả chi tiết từng loại.
  • Lưu trữ trạng thái phía Client (Browser Cookie & LocalStorage Fallback) tương thích 100% Page Cache.
  • Quản lý phiên bản Consent Versioning (Bấm reset yêu cầu khách xác nhận lại khi đổi chính sách).
  • Phương thức chèn nút Cookie Settings: Shortcode [learnpress_cookie_settings], Gutenberg Block, PHP Function.
  • Cảnh báo xung đột (Notice) trong wp-admin khi phát hiện các plugin cookie khác đang active.
  • Developer API: JS Object window.LP_Cookie, Custom Event learnpress/cookie/consent_updated, PHP Hooks.

5. UI References

Chi tiết thiết kế giao diện Admin Sub-tabs, Banner Frontend và Popup Modal tham khảo tại tài liệu: 04-ux-and-wireframe.md.

6. Technical Notes

  • Frontend: 100% Vanilla JS (Zero jQuery), JS < 15KB gzipped, CSS < 5KB gzipped, thời gian thực thi < 30ms.
  • Caching: Kiểm tra và render 100% Client-side sau khi trang load xong, không bị ảnh hưởng bởi LiteSpeed, WP Rocket hay Cloudflare CDN.
  • Accessibility: Đạt tiêu chuẩn WCAG 2.1 AA (hỗ trợ phím Tab, ARIA labels, Focus Trap, tương phản màu sắc).
  • Permissions: 100% quyền thuộc về Administrator. Instructor không có quyền chỉnh sửa.

7. Acceptance Criteria

  • Khách lần đầu truy cập thấy Banner ở Bottom Bar với Light Theme và 3 nút thao tác.
  • Bấm 'Accept All' hoặc 'Reject All' đóng banner ngay lập tức và lưu đúng trạng thái consent.
  • Tăng Consent Version trong Admin buộc tất cả khách phải xác nhận lại khi truy cập lượt tiếp theo.
  • Bật LiteSpeed/WP Rocket Cache không làm vỡ giao diện hay dính cache trạng thái của người dùng khác.
  • Không xuất hiện bất kỳ lỗi JS console nào và đạt tiêu chuẩn phím di chuyển bàn phím WCAG 2.1 AA.

8. Subtasks

  • Product: Chốt yêu cầu PRD và kịch bản nghiệm thu (Owner: Product Team)
  • Design: Thiết kế giao diện Admin Sub-tabs và Banner Frontend (Owner: UI/UX Team)
  • Engineering (Backend): Lập trình WP Admin Settings, Options Storage, PHP Hooks (Owner: Backend Dev)
  • Engineering (Frontend): Lập trình Vanilla JS Script, Banner UI, Modal Focus Trap, Custom Events (Owner: Frontend Dev)
  • QA: Thực thi QA Test Plan (WCAG 2.1 AA, Page Cache, Cross-browser) (Owner: QA Team)
  • Docs: Biên soạn bộ tài liệu 5 chuyên đề hướng dẫn người dùng và Developer (Owner: Technical Writer)
  • Marketing: Chuẩn bị bài viết thông cáo ra mắt và cập nhật Changelog (Owner: Marketing Team)

9. Release Notes

* Added: Native Cookie Consent module in LearnPress Core (LearnPress -> Settings -> Privacy & Cookies).
* Added: Support 4 default cookie categories (Essential, Analytics, Marketing, Preferences).
* Added: Client-side consent storage with 100% Page Caching & CDN compatibility.
* Added: Shortcode [learnpress_cookie_settings] and Gutenberg Block for Cookie Settings link.
* Added: Developer JavaScript API (LP_Cookie) and Custom JS Event 'learnpress/cookie/consent_updated'.
* Added: Admin conflict warning notice when 3rd-party cookie plugins are active.
* Improved: Accessibility support meeting WCAG 2.1 AA standards.
